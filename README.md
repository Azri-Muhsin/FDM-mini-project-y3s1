## 📌 Project Overview
This project was developed for the **Fundamentals of Data Mining (FDM)** module (Year 3, Semester 1). It focuses on performing end-to-end data mining on a car insurance dataset to extract insights and build predictive models.

The goal is to assist insurance companies in risk assessment by predicting both the likelihood of a claim and the potential cost involved.


## 🎯 Key Objectives
1.  **Exploratory Data Analysis (EDA):** Visualizing patterns in policyholder demographics and vehicle history.
2.  **Classification:** Predicting **if** a policyholder will make a claim (Binary Classification).
3.  **Regression:** Predicting the **possible claim amount** if a claim is made.
4.  **Deployment:** Providing an interactive interface using **Streamlit**.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
* **Web Framework:** Streamlit

## 📂 Project Structure
* `app.py`: The main Streamlit application file.
* `notebooks/`: Jupyter notebooks containing the detailed EDA and model training steps.
* `models/`: Saved `.pkl` files for the classification and regression models.
* `data/`: The car insurance claims dataset.
